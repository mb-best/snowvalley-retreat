# 雪隐山居 · 云岫山境

首个可游玩的完整山境，使用 Three.js r160。Unreal Realism / Stylized 是美术方向，并非使用 Unreal 引擎。

## 定稿与坐标

- 唯一来源：用户 2026-10-27 上传的最终地图，修订 1597，331 个要素。
- SHA-256：`cf6959526d1ce86c1acaed4ac1743f38ba697a26260ce82396389c90b4c5f757`。
- 地图 20,000 × 16,000 米；401 × 321 高度网格，50 米间距。使用编辑器的 `fieldFor` 解析全部定稿等高线与地形基础，冻结为 Float32，不重新设计山体。
- X 向东、Z 向南，上北下南；世界原点为地图中心；Y = 绝对海拔 − 1700 米。
- 玩家脚下与地形网格使用相同的三角形插值；256 米近景补片以 2 米采样改善照明连续性，不添加新的高度。
- `terrain-map-1597.html` 使用独立草稿存储加载同一份地图；后续手工编辑不会悄悄改动本世界。

## 已实现

- 全幅地形，20 处湖泊、7 条河流、46 条曲线步道、106/85 米两座瀑布、6 处步道涉河桥及连续坡道。
- 栖云村、松烟村、溪隐村各 11 栋建筑；栖月、听松、晴岚山庄各 4 栋，包括专门的主楼，共 45 栋。
- 瑞士山镇木石建筑：石砌基础、灰泥墙、木构上层、挑檐瓦屋顶、阳台、百叶窗、花箱、烟囱与炊烟。按真实地面角点安置基础，在定稿位置附近选址，不削平山坡。
- 日光、云层、远景雾、夜间暖窗；近湖平面倒影、水面波光、瀑布与水雾。轻盈画质关闭倒影。
- 7 类生态树木组合，4 类灌草、5 类花卉、5 类岩石；近景树皮与苔藓、叶面细节、风动草叶，远景树林使用简化交叉植片。
- 依据最终生态网格、海拔、坡向、湿度及坡度混植针叶与阔叶种类。林线最高 3500 米、草甸线最高 4000 米，以过渡带逐渐减稀；北纬 32° 的日照方向。树种名称为生态组合的视觉代表，不是植物分类学标本。
- 每次新游戏用 `crypto.getRandomValues` 从三个村庄中等概率选择出生地，山庄不参加抽选。
- 第一人称与带动画旅人的第三人称切换；行走、跑步、跳跃、房屋/树干碰撞、地面与桥面跟随；第三人称镜头避让地面与建筑。
- 马匹骑乘、呼唤，犬只互动跟随，牦牛和牧草投喂；四类植物采集与约一分钟再生。
- 山居手记、地点到访记录、快速前往、地图/小地图、拍照保存、四季/时间/天气控制、自然音、触屏摇杆。
- 本世界单独保存浏览器进度，以定稿哈希校验；不覆盖旧世界存档。

## 入口和操作

游戏：`/yunxiu-world.html`。地形对照：`/terrain-map-1597.html`。旧世界、晴日山谷与原地图工作台仍可进入。

WASD/方向键移动，拖动环顾，单击请求鼠标锁定，Esc 释放；Shift 快走，空格跳跃，V/C 切换视角，E 互动，R 骑乘/下马，M 地图，J 手记，H 帮助，P 拍照模式。手记的“足迹”可前往主要地点。

## 外部资源与自建

Kenney Nature Kit / Mini Characters：CC0，自带纹理的 GLB；Poly Haven Mossy Rock：CC0，颜色、法线与粗糙度贴图；Three.js 官方加载器与 Reflector：MIT。许可与原始来源保存在 `dist/yunxiu/assets/`，详细见 `YUNXIU-ASSETS.md`。运行时使用本地资源，无外部模型站点依赖。

查找后没有合适且可用的轻量瑞士建筑资源，因此建筑自建；材质与近景细节沿用晴日山谷的绘画/PBR 混合基础。不是用通用农舍替代瑞士山镇。

## 复现与验证

`node scripts/build-yunxiu-world.mjs <final-map.json>` 生成冻结世界数据。只有明确要更新最终地图时才重跑。

`node scripts/check-yunxiu-world.mjs`：定稿来源、三角形地面、三个随机出生村庄、生态高度上限、模型自包含/许可、动画、DOM 接线和要素几何一致性。

`node scripts/check-yunxiu-scene.mjs`：实际 Three.js/GLTFLoader 构建几何，检查 45 栋房屋、3 座主山庄、全部村庄出生点、所有目的地落脚点、动物落位、桥梁与河岸连续性、实例矩阵、117 个材质钩子和着色器引用展开、湖面反射几何。此测试显式模拟 Canvas 和图像解码，不是浏览器测试，也不验证 GPU 编译或图像。

本地 HTTP 资源检查已通过。当前工具连接无法进行真实浏览器和 GPU 渲染验收，帧率、屏幕画面、镜头观感和完整键鼠体验仍待实际设备体验；不能把几何测试结果当成最终美术验收。
