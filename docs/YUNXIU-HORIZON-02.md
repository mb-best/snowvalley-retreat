# 云岫山境 · 边界连续性 horizon-2

2026-10-31。基线为网页版 main `382433808101e1e2dbc92584c6f3383f0f617a4a`。

针对高空画面中的外围条带、拉伸山墙和矩形接缝：

- 边缘地势按物理距离逐步滤波，真实的边缘坡度向外衰减，逐渐过渡到使用二维世界坐标生成的山岭。拐角用两条边的延伸共同构造；移除角度与距离正弦叠加产生的环状起伏。
- 外围地形从 22 环增加到 42 环，最内层 12.5 m，逐步降低远处精度，外缘延伸至 156 km。增加约 5.8 万个三角面；不改变活动范围或原始地形数据。
- 活动地形、近地精细网格和外围使用相同的接缝法线。外围生成后隐藏旧的垂直封边裙。
- 移除拉伸的环形噪声贴图，用统一的世界坐标岩石材质和多尺度林冠颜色。接缝处颜色不额外染色，河床贴图越界采样逐渐消失。
- 外围地面恢复不透明写深度；雾浓度与内景一致。天空下半球渐进匹配同一雾色，避免高空看见一张独立地毯。
- 林地边界外延续 3.5 km 的同款树木剪影；靠近边界 260 m 内使用现有树种的实体模型。外围植被只参与画面，不参与碰撞或存档。
- 六条出境河道、三层远山、昼夜天气季节与原有地图、存档及飞行上限保留。

## 验证

- 边缘 1441 点高度最大误差约 `3.1e-11 m`，接缝法线误差约 `4.5e-8`。
- 边缘内外坡度、四角连续性、实体深度写入、取消拉伸贴图和缩短雾效、六河顺坡、全景闭合、8000 m 相机与原地形不变均有检查。
- 既有 world、life、travel、recording-wildlife、controls、scene 检查通过。Pages 流程加入 horizon 检查。
- `horizon-review.html` 提供四边的谷口和山脊、四角共 12 个固定位置，支持地面、近空、8000 m，朝外、沿边界、朝内、垂直俯视，以及夏冬、晴雾夜间，便于实际 GPU 画面复核。它复用正式地形、水系、材质、天空和远景模块。

网页版工作目录独立；不修改 UE5 / Blender 分支或资源。
