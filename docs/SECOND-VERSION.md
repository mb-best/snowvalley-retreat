# 雪隐山居 · 第二章：翻山听澜

体验地址：https://snowvalley-retreat.docilegoose18.chatgpt.site

## 世界与路线

世界边界约 16.4 × 20.5 公里，总面积约 335.5 平方公里。可自由离开古道探索；这里的面积是程序地形的覆盖范围，并不代表每个角落都有手工制作的内容。

从海拔 2000 米的雪隐村出发，沿约 16 公里的山间古道穿越森林、疏林、花甸与岩坡，经过海拔 3800 米的望雪垭口，走向山另一侧海拔 2000 米的听澜村。村子远离山脚，附近的云落瀑布从林间岩壁落入水潭。东侧照雪峰最高 5000 米，可自行攀行。

山体采用宽阔台地、缓坡与侧脊相连的结构。主要古道每 8 米采样检查过连续坡度，最大升降约 0.49 米/水平米；个别侧峰、岩壁和瀑布仍保留陡坡。

| 海拔 | 地貌 |
| --- | --- |
| 2000—2600 米 | 茂密山地森林 |
| 2600—3200 米 | 稀疏针叶林 |
| 3200—3550 米 | 灌木与鲜花草甸 |
| 3550—4100 米 | 高山岩石坡地 |
| 4100—5000 米 | 雪线以上山地 |

映雪海子湖面位于海拔 3200 米，在疏松林与高山花甸交界。不同海拔带都有横向活动空间。春夏秋冬、昼夜、天气、骑马、狗伙伴、牦牛喂养与植物采集保留。

## 地图与操作

右下角实时小地图显示位置、朝向、海拔、地貌带、古道和地标。＋/− 或滚轮缩放，拖动平移；“定位”恢复跟随，“全境”显示整个世界。M 打开完整地图，13 个地标支持直接前往，也可以全程徒步或骑马。翻越垭口会留下足迹记录。

WASD 移动，鼠标拖动环顾，Shift 快行/骑马奔跑，Space 跳跃，E 互动，R 上下马，J 打开山谷手记。触屏保留摇杆与互动按钮。

旧版背包和伙伴存档继续使用；新世界的地标发现与翻山记录独立记录。存档在当前浏览器中，不会自动跨设备同步。

## 距离 Tidewater 的写实效果还差什么

本版完成了更大的世界结构和探索功能，画面仍是程序化原型。真正影响写实程度的下一步，是精细素材、材质和光照的共同升级。

1. **先做映雪海子周围约 500 米的精细样板区。** 使用岩石、土壤、苔藓、草甸与积雪的 PBR 材质，加入法线、粗糙度、按坡度混合、湿润与融雪过渡。山体中尺度侵蚀、碎石堆、岸线细节需要人工检查和修整。
2. **升级植物、岩石和动物。** 替换目前简化的树木与动物几何，使用真实尺度的针叶树、灌木、草花、扫描岩石与带骨骼动画的马/狗/牦牛；增加植物种群分布、风摆、枯木和林下细节。
3. **升级天空与光照。** 大气散射、太阳/月亮光照、云影、远近分层雾、环境遮蔽、稳定的远近阴影以及统一的曝光和色彩处理，需要作为一个整体调校。天气应影响地面湿度、能见度、积雪与声音。
4. **升级水体。** 为湖面加入岸边深浅变化、可靠倒影与波纹；溪流加入方向流动、石头绕流与泡沫；瀑布加入更细的水丝、水雾与落水冲击。
5. **把样板区的质量扩展到大地图。** 分块加载、远近模型切换、实例化、压缩纹理和资源预算决定能否在普通电脑上维持流畅。先把一个区域做对，再推广，比只增加世界面积更能提高真实感。

用户之前遇到过 WebGPU 适配器与计算管线错误。本版继续采用 WebGL；后续可优先在现有渲染路径上升级，若增加 WebGPU 高画质模式，应保留可用的兼容模式。

## Tidewater 源码可以怎么复用

Tidewater 的项目代码采用 MIT 许可，可以修改与复用，但需要保留版权与许可。它的第三方素材按各自许可处理，不能把代码许可直接套到所有素材上。

本版已实际引入它独立的 CPU 地形噪声/侵蚀辅助代码，固定到提交 `4811ba48d795197de5621985f404e765c0b7c0ef`，保留完整许可与来源。山体的高程骨架、路线、地貌带和村庄是本项目的新实现。

| 部分 | 复用方式 |
| --- | --- |
| 地形噪声、侵蚀辅助 | 独立程度高，已复用 CPU 辅助函数 |
| 山地生成 | 可借鉴侵蚀、坡度与材质遮罩；需重新设计高原山谷的地形骨架 |
| 植物与岩石 | 可借鉴分布、实例化、远近细节管理；材质、模型和渲染接口需要适配 |
| 天气、天空、昼夜光照 | 可研究时间和天气参数组织；WebGPU/WGSL 着色与计算管线需要移植或整合相应渲染器，不能直接复制即用 |
| 扫描模型、纹理、声音 | 逐项核对第三方许可；本版没有打包这些素材 |

## 验证与边界

已验证 10,374 个地形采样、关键海拔、古道连续性、海子位置、13 个地标与资源导入；浏览器中验证了实际翻越垭口、地图定位/缩放及主要场景。大世界使用地形细节分级、远景树卡片与近景实例，整体仍需要更广泛的设备性能测试。动物照料仍是轻量采集/喂养循环，没有繁殖、疾病或完整牧场经营。
