# 《雪隐山居 · 云岫山境》原生美术制作路线

2026-10-29。目标：明媚多彩、梦幻写实的高山生活世界。**正式制作主线采用 Unreal Engine 5 桌面实时渲染，Blender 制作可编辑资产。** 网页继续提供现有可玩版本、地图编辑、美术展示与版本入口。引擎路线已经选定；原生实景、最终资产和性能尚未实现或验收。

## 选择依据与本次范围

已读取两份用户导出的美术选择文件，内容一致：01 整体氛围、02 人物、03 马犬牦牛、04 风神翼龙坐骑、05 植被、07 岩石地表水下、08 生灵四季均选择 `like`。本次对话明确授权按此方向分步制作，覆盖导出 JSON 中通用的“非自动制作授权”说明。06 建筑路桥没有选择记录：沿用先前瑞士木石建筑要求，先做一栋样品，再根据实景反馈定型。不能因 05/07 背景中的中式建筑重新改变建筑主题。

本轮完成路线调研、资源候选核查、定稿地图转换工具、技术验收数据和 Blender 地形导入脚本。没有把新概念图当成三维交付，也没有更换当前在线游戏的模型。

## 为什么选这条路线

| 工作 | 工具与结果 | 采用理由与约束 |
| --- | --- | --- |
| 正式可玩世界 | Unreal Engine 5，优先本机桌面体验 | 大世界分区、动态光照、材质、水体、动画和性能分析具有完整工具链；实际画质仍取决于资产和制作，换引擎不会自动生成好画面 |
| 单体资产 | Blender，保存 .blend，导出 FBX/GLB 和独立贴图 | 雕刻、拓扑、UV、烘焙、骨骼、动画和程序化变体可以持续修改，避免只有一个不可编辑的合并模型 |
| 公共材料 | Poly Haven、ambientCG 等逐项核查的免费素材 | 优先 CC0；自然扫描素材需要统一造型、色彩、尺度与性能，不能下载后直接混装 |
| 图片生成 | 概念补充、正侧背面方案、材质与服装变化 | 用于设计和沟通；生成的多视图可能互相矛盾，仍需人工/脚本核对结构，不等同已经有网格、动画或碰撞 |
| 高质量静帧 | Blender / 引擎内渲染，标明渲染方式 | 单体及构图验证有用，但交互验收必须使用可玩版本、相同机位和连续运动画面 |
| 地图与发布 | 原定稿 JSON/F32 + GitHub 版本管理 | 保留地图身份、资源源文件、规则和版本；GitHub Pages 承载网页和介绍，不能直接执行 UE 桌面程序 |

Unity HDRP、Godot 或继续增强 Three.js 均存在实现可能，但本项目近景材质、复杂植被、动态水岸与远山目标更适合优先验证 UE5。此为本项目的工程判断，不是宣称其他引擎无法做到。首轮不并行维护多个新引擎。

UE5 的游戏开发许可允许先行开发；达到许可规定收入条件后另有版税义务。Blender 可免费用于创作。先使用免费工具和许可明确的资源，不把付费生成服务、商城包或云 GPU 作为默认依赖。采用之前应保存各版本实际许可；不将 UE 引擎代码和受限商城源资产公开放进现有 GitHub 仓库。

## 画面怎样接近参考图

画面的核心是可信的结构，加经过设计的色彩、光线和生活痕迹。山体保持大轮廓，近处用真实裂隙、根系、花草分层和地表过渡补细节；暖日光与冷天光有共同方向，阴影能看见材料，不靠高饱和度和泛光覆盖问题。

| 类别 | 首个样品的制作要求 |
| --- | --- |
| 岩石与山体 | 一块近看成立的岩石、一个断崖段；几何表现大断面，法线表现颗粒，苔藓只在合适湿阴部位分布；远山的峰脊、岩层和积雪形态统一 |
| 植被 | 一株阔叶、一株针叶、灌木、草、花、蕨和林地碎屑；树干接根系、主枝承接叶簇，叶片有透光和间隙，风动分级，先处理透明闪烁和远景切换 |
| 湖岸 | 湿土—砾石—浅滩—深水连续，波纹、深度色、真实环境反射及水下衰减协作；入水后玩家和碰撞都以同一湖床为准 |
| 建筑 | 一栋瑞士木石小屋，真实厚度的屋檐、窗洞、阳台和台基；木纹方向、石块尺度、花箱和堆柴经得起走近观察；作为待审建筑样品 |
| 人物 | 按 02 的自然成人比例制作一位旅人，先体块和服装轮廓，再面部/头发/织物；第三人称行走、跳跃、斜坡站立和入水需要连续演示 |
| 动物与坐骑 | 马、犬、牦牛各自的结构与步态分开验证；飞龙先验证长颈长喙、四肢式翼龙骨架、收翼、起飞和落地，再精雕与毛膜材质 |
| 四季与生活 | 明亮夏日为第一套标准，随后做同机位秋冬春对照；鸟、蝶、鱼和细小生活物件在主要场景达标后加入 |

免费资产初筛已列在 [asset-shortlist.json](asset-shortlist.json)。已核查 Boulder 01、Fern 02、Pine Tree 01、Rock 01 的作品页及 Poly Haven CC0 许可；这些仍是候选，没有宣称已经下载、通过网格检查或成为最终资产。人物、动物、瑞士屋、风神翼龙没有核实到全部匹配的免费成品，将分别挑选基础资源或定制。

## 第一个实景放在哪里

建议选择**晴岚山庄—风镜湖西岸**。它能在不移动任何定稿地标的前提下，把木石建筑、花坡、针阔混交林、湿岩、浅水和远山放进同一观察序列。

- 取约 1 km × 1 km 的地形作为背景与步行上下文；其中约 200 m × 200 m 为第一块精做区域。
- 晴岚山庄的现有位置距最近湖岸约 281 m，现有地形有约 87 m 的高差。建筑不挪到湖上；分别安排山庄视角、林缘下行视角与湖岸视角。
- 首批实物：一栋木石屋、一组岩石与湿岩、两类代表树、灌草花组合、一段可入水浅岸及一位旅人。人物和翼龙体块另设同尺度检查台。
- 现有地图最高约 6842 m；若从此地不能按参考图看到合适雪峰，应调整镜头、景观细节和构图，不能为构图偷偷移动定稿山峰。

## 必须先验证的技术问题

**1. 地图迁移必须比较真正的曲面。** 原始 401 × 321、50m 间距网格保留为不可变基准。导出试验发现，即使 16 位高度编码误差只有 6.25 cm，直接将它重采样成 2521 × 2017 再三角化，在原采样点最大也会产生约 **35.025 m** 曲面偏差。因此该文件明确标为“导入预览”，不能替换定稿地形。

同时提供保留原采样点的 505 × 379 合法 Landscape 导入尺寸，额外顶点只在世界边界外作填充；活动范围仍为 20 × 16 km。它保留原顶点位置，但原生引擎的三角对角线仍须现场验证。原始 F32 网格以及相同对角线的 Blender 参考网格作为曲面校验依据。提高顶点数不会凭空获得岩层或侵蚀细节。

**2. 玩家修路采用真实可变网格验证。** 现有 Earthworks 算法已导出一条 4m 宽步道的横断面数值，作为原生移植的比较基准。优先试验小范围分块可变高度场，路面横向水平、路肩连续填挖、受影响块重建碰撞；未编辑的大范围地形使用成本较低的静态表示。静态和动态表示切换必须只有一份有效表面与碰撞，不能把两层相交的地面叠起来。若混合方案无法可靠交接，改为统一的分块网格地形，并先测近景与远景成本。

编辑器的 Landscape Edit Layers 不视为成品游戏中可直接挖填的方案。Epic 的 Dynamic Mesh 支持运行时修改，但有渲染与性能限制，不能假定它同时具有 Nanite/Lumen/自动 LOD 能力。因此**带可变地形的实景表现和帧耗**是第一轮路线是否成立的条件，先测再扩展。

**3. 水与地面共用几何定义。** 湖面、湖床、河流纵剖、瀑布上下端、岸坡、碰撞和游泳深度共用数据。原有 20 湖、7 河、106/85m 两座瀑布及 8.75m 最大湖深已作为转换基准导出；不把编辑器“水组件已放置”当成贴岸已经正确。先在小样板验证反射、透明、水下与水岸连续，再推广。

**4. 植被由生境驱动。** 保留原生态网格、北纬32°与上北下南方向。3500m 乔木、4000m 草甸为最高上限；密度和品种按海拔、坡向、日照、湿度、土层、坡度和风口连续改变。PCG 负责按规则放置经过打磨的资产，不能代替资产质量与生态判断。季节只在新游戏随机或由玩家切换；不让 PCG 或时间系统擅自推动四季。

**5. Mac 兼容与性能。** 本次只能确认执行环境为 Apple Silicon，内存与芯片具体型号未核实；常规路径和命令行没有找到可调用的 UE/Blender 编辑器。Epic 当前文档将16GB列为最低内存、32GB以上为建议，并对 Mac 的 Nanite、光追等功能标注设备和成熟度限制。首轮以兼容的桌面配置做 1080p / 30fps 目标，记录实测硬件与帧耗；不开实验功能作为必备前提。适配版本在实际安装与空场景预检后固定，不预先保证某个渲染特性或60fps。

## 本轮工具怎么复现

在仓库根目录运行（仅需 Node，无第三方依赖）：

```sh
node scripts/export-native-terrain.mjs
node scripts/check-native-terrain.mjs
```

产物在 `production/native/generated/revision-1597/`：原始 JSON/F32 完整副本、两个标明用途的 R16、所有有效地图对象及平滑曲线、原生态数据、水系纵剖、5m上下文/1m湖岸参考网格、修路横断面对照、文件哈希与测试报告。46条原预设路径仅保留在源档案中，不进入活动场景对象。

本机具备 Blender 后，可用下列脚本生成可编辑的**技术地形参考**：

```sh
blender --background --python production/native/blender/import_geography.py -- \
  --bundle production/native/generated/revision-1597 \
  --output production/native/generated/yunxiu-geography.blend
```

脚本创建米制地形，保留原始网格三角方向；全境粗网格和1m细网格起初隐藏，避免与5m上下文重叠。它未添加最终资产、光照、水材质、玩家或碰撞，不能把生成该文件称为美术样板完成。当前未在 Blender 或 UE 内实际执行，尚无原生截图、视频、可执行程序或帧率结果。
