# 云岫山境 · 边界外远景 horizon-1

2026-10-30。基于已发布的 travel-1（f06738188bcadb71ca941e6a9abb2d044b9a00be）更新网页版。

## 呈现方式

- 20 × 16 km 活动世界四周增加仅用于观看的外围地形。内圈逐点采用定稿地图的 50 m 边缘顶点和高度，延续边缘坡向，再逐渐过渡至外围山岭；没有修改定稿高度数据或玩法边界。
- 外围地形附加烘焙的森林冠层、草坡开口贴图，沿用世界地表的岩石材质及季节积雪规则。共增加 60,480 个地形三角面，不在外围生成完整树木或建筑实体。
- 天空接入三层首尾相接的 360° 山景贴图，按实际边缘地貌生成各方向的高低山势，虚拟距离分别为 110、180、300 km。地形尽头渐隐到大气远景，不呈现可见的矩形尽头。
- 远景投影根据相机位置、高度和地球曲率调整。玩家飞高后，远山随视角下移；昼夜、阴雨和冬季会改变远景色调、清晰度及积雪。
- 地图边界处六条出境河流延续为弯曲、逐渐下降的外围河道，并在其下方塑造谷地，向远方渐隐。
- 近景地形材质在活动矩形外裁切，避免靠近边界时局部高精度地形与外围景观重叠。

上述外围景观不加入碰撞、导航、建造、地图数据或存档。行走、骑马和飞行仍受现有边界限制；原生 UE5/Blender 目录和分支独立。

## 验证

- `node scripts/check-yunxiu-horizon.mjs`：1441 个边缘位置的高度连续、360° 闭合、所有外围顶点有限、六条出境河流顺坡、相机高度参数、资源释放，以及原始高度数据未被改动。
- 现有 world、life、travel、controls 和 scene 检查通过；覆盖地形、水系、移动边界、飞行上限、地图导航、相机、建造和存档的相关逻辑。
- scene 检查因目录包含中文及空格，以 `/tmp/yunxiu-horizon-check` 的符号链接入口配合 `--preserve-symlinks-main` 运行，避免既有测试脚本的 URL 路径重复编码问题；游戏文件正常使用 URL，不需要此处理。
- 本环境不允许监听本地 HTTP 端口，浏览器自动连接未成功；未将几何和 shader 源码检查当作 GPU 画面或帧率验收。仍需在实际设备查看山景接缝、晴雨昼夜及高空视角的观感。

入口：`yunxiu-world.html?v=horizon-1`。
