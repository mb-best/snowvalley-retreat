# 雪隐山居 · 第二章：翻山听澜

## 晴日山谷 · 独立美术样板

打开 [`dist/sunny-valley.html`](dist/sunny-valley.html)，或在本地服务器访问 `/sunny-valley.html`。这是可自由漫游的独立晴日场景：林间小屋、流动溪水、拱形木桥、花坡与成组树林。采用本地 Three.js、实例化植被、树叶材质、暖阳阴影和远景雾。电脑使用 WASD / 方向键行走、鼠标拖动环顾、Shift 快走、空格跳跃；触屏有摇杆与跳跃按钮。顶部的三个地点可切换观景视角，进入后可前往相应区域。

详细说明和资源来源见 [`docs/SUNNY-VALLEY.md`](docs/SUNNY-VALLEY.md)。

可探索的连续 3D 山谷世界。第二版扩大到约 16.4 × 20.5 公里：从海拔 2000 米的雪隐村，沿古道越过 3800 米的望雪垭口，抵达山后的听澜村与云落瀑布；照雪峰最高 5000 米。

## 已实现

- 第一人称漫步、快行、跳跃与山坡攀行；骑马与下马。
- 村口马匹“踏雪”，支持呼唤、骑乘和奔跑。
- 牧羊犬“阿旺”，亲近后成为跟随伙伴。
- 五头会缓慢漫游的牦牛；采集牧草后可以喂养，照料记录会保存。
- 四种可采集植物，具有季节限制；采集后约一分钟重新生长。
- 昼夜光照、星空、月光、夜晚村庄灯火与炊烟。
- 晴、多云、薄雾、雨与雪，可以自动变化或手动选择。
- 春夏秋冬：地表、针叶林、阔叶树、屋顶积雪、湖面及可采集植物随季节变化。
- 五个连续海拔地貌带：茂密森林、稀疏针叶林、灌木花甸、岩石坡、雪域。映雪海子湖面在海拔 3200 米的林线/花甸交界。
- 两座村庄、13 个地标、连续翻山古道与翻越垭口记录。
- 常驻小地图与全景地图：实时位置/朝向、缩放、拖动、全境视图与跟随定位。
- 发现记录、自然环境音和照片下载。
- 植物背包、狗伙伴和牦牛照料进度保存在当前浏览器中。
- WebGL 渲染，不需要 WebGPU、AI API Key 或额外模型订阅。

## 开始探索

点击“走进山谷”。村口有牧草和阿旺。靠近植物或动物后，按 E 或点击画面中的互动提示。

右上角“山谷手记”可以切换季节、天气和时刻，呼唤动物，查看背包与足迹。地图标记可以直接前往。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 环顾 | 鼠标拖动；点击画面锁定鼠标，Esc 释放 |
| 快走 / 骑马奔跑 | Shift |
| 跳跃 | Space |
| 采集 / 喂养 / 亲近 / 上马 | E；也可点击互动提示 |
| 骑马 / 下马 | R |
| 地图 | M |
| 山谷手记 | J / H |
| 取景模式 | P |
| 保存照片 | 右上角相机按钮 |

触屏设备有移动摇杆、拖动环顾与互动按钮；建议优先在电脑上体验。

## 运行本地副本

在本文件所在文件夹打开终端，运行 `python -m http.server 5186 --directory dist`，然后在浏览器中打开 `http://127.0.0.1:5186`。也可使用任何静态网站服务器。

请通过 HTTP 访问，直接双击 HTML 会受到浏览器对模块文件的限制。

项目使用本地打包的 Three.js、原生网页代码及带 MIT 许可的 Tidewater CPU 地形辅助函数。中文衬线字体会尝试加载 Google Fonts；无法联网时使用系统字体，世界和操作仍可运行。

## 当前版本的范围

这是可玩的世界原型，场景和动物使用程序生成的模型与纹理，整体采用自然山地配色；还没有达到照片级写实或 Tidewater 长期打磨后的精细程度。牦牛照料目前是采集和喂养循环，尚不包含繁殖、疾病、牧场扩建。没有房屋编辑、联网多人、复杂动物 AI 或真实气象模拟。

一个昼夜约 12 分钟，一个季节约 6 分钟，天气约 100 秒发生一次变化。时光、季节、天气都可独立暂停自动变化。湖面冬季呈现结冰外观，但湖区仍禁止穿行。

## 文件

- `dist/index.html`：界面与中文内容。
- `dist/style.css`：界面样式与移动端适配。
- `dist/math-v2.js`：高程、地貌带、路线、湖泊/溪流、地标与植物；`math.js` 是兼容入口。
- `dist/alpine-world.js`：分块地形、远近植物/岩石、两座村庄、溪流与瀑布。
- `dist/alpine-map.js`：地形底图、实时位置与交互缩放。
- `dist/world.js`：共享基础场景、房屋、动物、四季、天空和雨雪；第二版地形由 Alpine World 实现。
- `dist/app.js`：行走、互动、手记、地图、声音、存档。
- `dist/vendor/three.module.js`：Three.js r160.1，MIT 许可。
- `.openai/hosting.json`：Sites 部署配置。
